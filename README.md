# 皮卡丘 · 电能冲刺

基于七牛云 XBuilder / SPX 的 2D 跑酷游戏，附可离线打开的浏览器试玩版。当前版本：**v6**。

## 开始试玩

下载本仓库后，用浏览器打开根目录的 `index.html`，无需安装依赖或启动服务器。

- **空格 / ↑ / 点击画面**：跳跃，支持二段跳。
- **X**：电光一闪，短暂加速并免疫碰撞，附黄色光环、闪电和拖尾；冷却 4 秒。
- **R**：重新开始。
- **P**：暂停 / 继续，仅本地网页版支持。

躲避精灵球，收集电能球。每颗电能球加 10 分，靠近时自动吸取。

## 导入 XBuilder

1. 下载 [`dist/pikachu-electric-v6.xbp`](dist/pikachu-electric-v6.xbp)。
2. 在 [XBuilder](https://x.qiniu.com/) 新建项目，选择导入项目文件。
3. 导入 `.xbp` 后运行。

舞台为 **480 × 360**，精灵缩放 **100%**。本地网页采用相同的坐标、素材和核心玩法。

## 本版内容

- 六帧高清皮卡丘跑步动画。
- 远景与地面双层循环滚动。
- 精灵球和电能球独立随机出现，使用预先创建的对象池。
- 回收时隐藏，重生先定位再显示，避免向右刷新的轨迹。
- 电光一闪使用独立的预加载光效精灵，跟随角色跳跃。

## 文件说明

| 路径 | 用途 |
| --- | --- |
| `index.html` | 可直接打开的离线试玩网页，素材均已嵌入 |
| `project/` | XBuilder 舞台、精灵 SPX 源码及 PNG 素材 |
| `dist/pikachu-electric-v6.xbp` | XBuilder 可导入项目 |
| `dist/pikachu-electric-v6-source.zip` | 源码和素材压缩包 |
| `web/index.template.html` | 本地试玩页面模板 |
| `scripts/build.py` | 用源码重新打包项目并嵌入网页素材 |

## 重新打包

需要 Python 3，仅使用标准库：

```sh
python3 scripts/build.py
```

修改 `project/` 中的素材后，重新打包会同时更新项目文件和本地网页中的图片。平台与网页的玩法代码分别位于 `project/main.spx` 和 `web/index.template.html`，修改玩法时需要同步两处。
